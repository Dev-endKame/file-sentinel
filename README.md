# SafeScan

Ferramenta de análise de arquivos para detecção de duplicatas, geração de hashes (SHA-256), verificação de integridade e geração de relatórios.

&gt; Projeto de portfólio para demonstrar boas práticas de desenvolvimento Python, arquitetura limpa e fundamentos de cibersegurança.

## 🚀 Funcionalidades

- Varredura recursiva de diretórios
- Geração de hashes SHA-256
- Detecção de arquivos duplicados
- Verificação de integridade
- Relatórios estruturados
- Logging profissional

## 🛠️ Tecnologias

- Python 3.14
- Git & GitHub
- VS Code
